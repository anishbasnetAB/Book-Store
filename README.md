# Book Store Management System

A web-based **Book Store Management** application built with **ASP.NET Core 6** and **C#**, allowing users to browse and manage book inventory with category support.

## Features

- Browse books by category
- Add, edit, and delete book records
- Category management with full CRUD operations
- Clean MVC architecture
- Responsive UI with Bootstrap

## Tech Stack

| Layer | Technology |
|-------|------------|
| Backend | ASP.NET Core 6, C# |
| Frontend | Razor Pages, HTML, CSS, Bootstrap |
| Architecture | MVC (Model-View-Controller) |

## How to Run

1. Clone the repo
2. Open `BookStore.sln` in Visual Studio 2022+
3. Run the application (`F5` or `dotnet run`)
4. Navigate to `https://localhost:{port}` in your browser
